# weihe
“卫禾守卫”成长教育守护平台是专为未成年人量身打造的智能化法治教育与 安全保护专属平台，核心以“智能化赋能、趣味化引导”为抓手，构建系统化、全 流程的未成年人法律学习与自我保护知识培养体系，切实筑牢未成年人成长安全防 线。 平台深度集成六大核心功能，形成完整学习闭环：法治课程板块汇聚专业师资 力量，打造分层分类、贴合未成年人认知的法治知识内容；守护任务以生活化、场 景化场景为载体，引导未成年人在实践中掌握自我保护技巧；挑战答题通过趣味互 动形式，激发学习主动性，强化知识记忆；学习记录实时同步学习进度与成果，方 便自主复盘；家长互动模块搭建家校沟通桥梁，实现家庭教育与学校教育的协同联 动；AI助理“禾苗同学”提供24小时个性化答疑与学习指导，精准匹配不同未成 年人的学习需求
